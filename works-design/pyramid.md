# pyramid · 金字塔

## 动作
**几何预研后推进**（Gate 2 出结论；Gate 0 提纲；**Gate 2 前不写 BuildStep**）

## 目标 / 难度
- L4 候选 · 预估 **12–16** 片（≤24）

## 红线预研（必须先算）
1. **禁止** square(75) 底 + equilateral triangle(71) 坡 → 71≠75。  
2. 合法路线二选一（或等价同族方案）：  
   - **全 75 族：** square 底 + right-triangle / large-triangle 坡（对接用腰/底 75）  
   - **全 71 族：** 无 75 方底，或 71 体系自洽底座  
3. 坡面倾角：能否 cardinal？若不能 → 仅允许**作品局部** posePolicy，边长规则不放宽。  
4. 顶点闭合须真实共边/共点可证，禁视觉糊弄。  
5. 总片数 ≤24。

## 剪影目标（预研通过后再锁）
- 正/侧：四面坡或层叠收束  
- 俯：方形/金字塔投影

## 共边 / 姿态
- 待 Gate 2 预研报告锁定族与姿态策略

## 视觉验收
- 预研阶段：只验收报告是否排除红线假设  
- 实现阶段：另开 Gate，人审剪影

## 教学
斜坡几何闭合；同族边长纪律

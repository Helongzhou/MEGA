# car · 小汽车

## 动作
**大改**（Gate 3；Gate 0 本文档定目标）

## 现状问题
方舱 + 竖立大三角「立牌顶」，侧视不像车。

## 目标 / 难度
- L2 · 4+ · 水平延展交通工具剪影  
- 目标片数：**9–12**（≤24）

## 片型配方（75 族为主）
| 片型 | 用途 |
|------|------|
| square | 舱段/底盘分段 |
| rectangle | 引擎盖/车尾（长75/短37.5） |
| window | 前挡风/侧窗 |
| right-triangle / large-triangle | 仅用 **75 对接边**（腰/底）做头尾斜坡过渡 |

## 剪影目标
- 正：车窗+前脸  
- 侧：前舱–座舱–车尾阶梯，**非**方盒立牌  
- 俯：矩形车身比例

## 共边 / 姿态
- 75↔75；37.5 短边仅互吸短边  
- 默认 cardinal；大改若需倾角须**另案局部** posePolicy（本阶段不预设）

## 搭建顺序（草案）
底盘/舱 → 前后分层 → 窗 → 斜坡过渡件

## 视觉验收
侧视一眼「车」；与 rocket/tower 剪影明显不同

## 教学
75 与 37.5 长短边；车身前后层次

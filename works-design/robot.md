# robot · 机器人

## 动作
**大改**（Gate 3）

## 现状问题
「带窗方柱」+ 大三角帽，角色肢体不清。

## 目标 / 难度
- L3 · 5+ · 头/躯干/臂/腿分块与镜像对称  
- 目标片数：**13–16**（≤24）

## 片型配方（75 族）
| 片型 | 用途 |
|------|------|
| square | 头、躯干、腿块 |
| window | 面部 |
| rectangle / right-triangle | 外伸手臂/肩（75 边对接） |

## 剪影目标
- 正：人形分块+表情窗  
- 侧：有厚度，臂可侧/前展  
- 俯：躯干居中双侧对称

## 共边 / 姿态
- 仅 75 族（含 rect 短边自洽）  
- 默认 cardinal

## 搭建顺序（草案）
躯干 → 头/窗 → 对称臂 → 腿

## 视觉验收
不再像竖箱子；肢体延伸可读

## 教学
镜像对称；角色部件拆解

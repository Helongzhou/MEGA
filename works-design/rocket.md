# rocket · 火箭

## 动作
**大改**（Gate 3）

## 现状问题
竖井方柱 + 前墙顶大三角，与 tower/robot 同质。

## 目标 / 难度
- L3 · 5+ · 细长箭体 + 对称外翼  
- 目标片数：**12–15**（≤24）

## 片型配方（75 族）
| 片型 | 用途 |
|------|------|
| square | 箭身段 |
| right-triangle | 侧翼：**腰 75** 贴箭身；斜边≈106 **不得**贴 75 |
| large-triangle | 锥顶/尾翼（底 75 合法对接处） |

## 剪影目标
- 正/侧：细长 + 外扩翼 + 尖锥收束  
- 俯：对称十字/星芒外扩  
- **差异：** 异于 tower 厚重收窄塔体

## 共边 / 姿态
- 翼根必须 75 腰↔方边；禁止斜边硬贴 75  
- 默认 cardinal

## 搭建顺序（草案）
箭身 → 对称翼 → 锥顶/尾

## 视觉验收
与 tower 并排可区分；左右翼对称

## 教学
左右对称装翼；斜边只作外轮廓不假吸

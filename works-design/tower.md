# tower · 高塔

## 动作
**大改**（Gate 3）

## 现状问题
双层井筒 + 大三角顶，与 rocket 体态接近。

## 目标 / 难度
- L3 · 5+ · 分层收窄 / 瞭望节奏  
- 目标片数：**14–18**（≤24）

## 片型配方（75 族）
| 片型 | 用途 |
|------|------|
| square | 各层井壁/盖 |
| window | 瞭望层 |
| rectangle | 女儿墙/垛口 |
| large-triangle | 仅在合法 75 底边处作塔顶特征（可选） |

## 剪影目标
- 正/侧：阶梯收窄或台座–瞭望–顶，有起伏  
- 俯：紧凑几何核  
- **差异：** 厚重高塔节奏 ≠ 细长火箭

## 共边 / 姿态
- 层间 75 对齐；收窄处真实共边  
- 默认 cardinal

## 搭建顺序（草案）
底座层 → 中段 → 瞭望窗 → 顶

## 视觉验收
与 rocket 并排可区分；高度感+错落

## 教学
高耸稳定；分层错落；瞭望空间

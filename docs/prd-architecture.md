# MEGA 完整产品架构（Gate 2 起）

`pages/build/index` 仍是 3D 搭建引擎与作品详情。产品外壳在它外面：

| 页 | 路径 | 职责 |
|----|------|------|
| 作品广场 | `pages/plaza` | 形态/主题筛选、搜索、热门/最新/件数、只看能拼的、进入搭建 |
| 我的库存 | `pages/inventory` | 分套 ±、合并计入、清零；拍照认盒仅为预告 |
| 搭建日记 | `pages/diary` | 完成记录、再搭一次、单条公开意愿 |
| 设置 | `pages/settings` | 音效、提示、公开展示总开关（默认关）、关于 |
| 搭建 | `pages/build` | 原 XR 引擎；`?workId=` 进入；搭完点提示记日记 |

## 硬规则（未改）

75 / 37.5 / 106 / 142 / 71 分族互吸；姿态默认 0/±90±10°；仅 house 双坡 `house-roof`；片数 ≤24；实施端不标 `accepted`。

## 库存匹配

「只看我能拼的」：作品每种形状需求 ≤ 已勾选套数的合并库存。缺一种即不能拼。热门：同一作品日记次数 ≥ 3。

## 公开

`publicShowcase` 默认 false。关闭时广场不渲染「大家的作品」。打开后也只列出日记里点了公开的条目。无 OCR、无审核后台。

house / flower 视觉仍待人工。本阶段不把它们标成 accepted。

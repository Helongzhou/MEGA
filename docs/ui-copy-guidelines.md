# MEGA 儿童磁力片小程序 · UI 视觉与文案规范（v1.1）

适用范围：首页（作品广场）、片盒（库存）、成就（日记）、我的（设置），以及 3D 搭建引导外围控件。

核心原则：儿童一眼看得懂、手指点得准、家长读着顺口，界面不出现开发或后台口吻。

改这四个页面时，必须同时遵守本文。3D 磁吸校验引擎不因文案或排版而放宽。

## 1. 布局与卡片

### 禁止

- 分类标签做成占满整行的竖向白条。首页分类可用圆角黏土块；筛选胶囊高度 64rpx–72rpx，左右内边距 28rpx，圆角 999rpx。
- 列表只有黑字和浅灰边框。卡片要有视觉锚点：预览、双色渐变、形状色块或大图标。
- 自定义导航与状态栏或胶囊重叠。使用系统导航栏时，不要再叠一层会钻进状态栏的自定义顶栏。

### 首页（广场）

1. 问候语 + 一句招呼：「嗨，小小建筑师」「今天准备好搭建超酷的作品了吗？」
2. 分类黏土块：全部 / 基础认知 / 立体城堡 / 交通工具 / 窗和房子。
3. 紫色「今日搭建」条，显示今天拼过几次。
4. 「接着拼」单卡 + 「为你推荐」双列网格。搜索占位、只看现有磁力片能拼的、排序胶囊保留。
5. 卡片右上角徽章为「热门」「可拼」或「差 X 片」。公开区仅在设置打开后显示。

### 片盒（库存）

1. 顶部薄荷绿汇总卡：大数字总片数 + 能拼几个作品。
2. 形状按「方片、窗和长条」与「正三角和六边形」分组。步进器紫色圆钮，不小于 72rpx。
3. 「拍包装盒识片数（即将上线）」放在列表底部，淡紫虚线卡，不悬浮遮挡。

### 成就（日记）

1. 顶部：「太棒了，你是搭建之星」+ 三列进度（拼过的作品 / 连续天数 / 点亮徽章）。
2. 徽章区 + 搭建记录列表。空态引导「去首页挑一个作品」。

### 我的（设置）

1. 称呼「小小建筑师」，显示手里片数。
2. 音效、搭建提示、公开分享用标准 `switch`（紫色）。
3. 「清空库存」单独放在底部，点击必须二次确认。

## 2. 色彩与触控

外壳页（首页 / 片盒 / 成就 / 我的）用淡紫黏土风，公共样式在 `styles/clay.wxss`：

| 角色 | 色 | 大约占比 |
|------|----|----------|
| 页面底 | 薰衣草 `#ECE9F7` → `#F6F5FA` | 65% |
| 卡片 | 白到浅紫 `#FFFFFF` → `#FAF9FE`，投影 `0 16rpx 32rpx rgba(114,101,227,0.08)` | 20% |
| 主按钮 / 选中 | 紫 `#8E82FE` → `#6D5CE7`，白字 | 10% |
| 强调条 | 薄荷绿 `#52B8AC`（片盒汇总） | 5% |
| 正文 | 墨蓝 `#2D3142`，辅文 `#8A8E9E` | — |

3D 搭建台顶底栏仍用暖石 chrome（`styles/tokens.wxss`），不挡 XR 画面。

核心按钮高度不少于 88rpx，相邻可点元素间距不少于 16rpx。步进器按钮不少于 72rpx。

## 3. 形状视觉

边长按主流 7.5cm 模数（Magna-Tiles / Connetix 级）。等长边才相吸；直角三角斜边约 10.61cm 只对斜边。

| id | 名称 | 颜色 | 图形 |
|----|------|------|------|
| square | 正方形 | `#38BDF8` | 圆角方块 |
| window | 窗户片 | `#34D399` | 方块加田字 |
| rectangle | 长方形 | `#FB923C` | 15×7.5cm 横条 |
| right-triangle | 直角三角 | `#FACC15` | 直角三角 |
| large-triangle | 大三角 | `#F87171` | 瘦高三角（非标准屋顶件） |
| triangle | 正三角 | `#A78BFA` | 等边三角，边长 7.5cm |
| hexagon | 六边形 | `#10B981` | 六边形，边长 7.5cm |

不要再在界面写「71mm」角标。

## 4. 文案

像幼教老师或玩具说明书，不像调试日志。

| 场景 | 不要写 | 要写 |
|------|--------|------|
| 首页招呼 | 欢迎使用本产品 | 今天准备好搭建超酷的作品了吗？ |
| 搜索占位 | 搜索作品 | 搜一搜：小房子、小花、城堡 |
| 库存筛选 | 仅看我能拼的 | 只看现有磁力片能拼的 |
| 库存说明 | 加减每一套的片数… | 调一调手里的磁力片数量，勾选多套可以合在一起算哦！ |
| 成就空态 | 还没有日记… | 还没有搭建记录呢，快去挑个作品动手试试吧！ |
| 公开开关 | 公开展示默认关闭… | 公开分享作品（暂未开放，开启前仅自己可见） |
| 拍照入口 | 拍照认包装盒 | 拍包装盒识片数（即将上线） |
| 关于 | 片与片必须真边相吸… | 从平面图形搭到立体小房子。边对边吸住，才算拼好。 |

硬规则：

1. 卡片副标题、空态、操作引导尽量一句说完，不套从句。
2. 界面不出现：状态、开关已关闭、标成通过、校验、字段、Mock、draft、accepted。
3. 按钮用动词：开始搭建、我拼好啦、去挑作品。不用「进入」「提交」。

## 1. 可用边长（MAG-001，禁止放宽）

| 边 | world | mm | 可互吸对象 |
|----|-------|-----|------------|
| 方 / 窗 / 长方长边 | 1.000 | 75 | 彼此；直角**腰**；大三角**底** |
| 直角腰 `RIGHT_TRI_LEG` | 1.000 | 75 | 同上 |
| 直角斜边 `RIGHT_TRI_HYP` | 1.414 | ≈106.1 | **仅同长斜边**（无墙/窗可吸） |
| 大三角底 `LARGE_TRI_BASE` | 1.000 | 75 | 同上 75 族 |
| 大三角腰 `LARGE_TRI_SIDE` | 1.894 | ≈142.0 | 仅同长大三角腰 |
| 正三角 / 六边 | 0.947 | 71 | **仅 71 族** — **禁止**贴 75 墙顶 |

说明：`edgesReallySnap` 长度阈为 `max(0.08, EPS_EDGE_LEN)`，71↔75 的 Δ≈0.053 **数值上会误过**；工程纪律仍按规格 **禁止** 使用该漏洞。本预研不采用 71 mm 片做屋顶。

## 2. 第二硬约束：位姿倾角

`validateMagnetBuild` 要求每步 `rx, rz ∈ {0, ±90°}`（容差 20°）。  
`verify_magnet.mjs` 另禁止 gallery 源码中出现约 50–80° 倾角字面量。

| 造型 | 典型倾角 | 现规则 |
|------|----------|--------|
| 竖立山墙（当前 large） | Rx=±90 | ✅ 通过 |
| 真双坡屋面（檐→脊） | ≈60°–74° 或 45° | ❌ **不过** |

因此：「看起来有侧面坡度」的真坡面，与「不改磁吸/倾角校验」**互斥**，除非单独开 **屋面倾角例外**（仍不放宽边长相等律）。

## 3. 方案 A — 两片直角三角形

### 3.1 A-竖山墙（前+后各 1，Rx=±90）

**连接表**

| 片 | 连接边 | 长 | 端点（世界） | 磁吸对象 | 角度 |
|----|--------|----|--------------|----------|------|
| 前直角 | 腰₁ | 75 | `(-0.5,1,0.5)→(0.5,1,0.5)` | 窗顶边 | 共线、反向；片平面竖直（同前墙） |
| 前直角 | 腰₂ | 75 | 自直角点竖直向上 | （自由边） | — |
| 前直角 | 斜边 | 106 | 直角对边 | **无匹配墙边** | — |
| 后直角 | 同构 | 75 | 后墙顶 | 后墙顶边 | 同前 |

**直角点必须落在檐的一端**（腰长 = 整段檐），山尖偏在左或右 → **不对称「披檐」轮廓，不是正中屋脊山墙**。

| 项 | 结论 |
|----|------|
| 边长磁吸 | ✅ 腰↔墙顶 |
| 倾角规则 | ✅ |
| 双坡 / 屋脊 | ❌ 仅前后竖板 |
| 正面可读「房」 | ❌ 弱（偏峰） |
| 侧面坡度 | ❌ |
| 片数 | 墙体 5 + 2 直角 = **7** |

**可行性：边长过、造型不及格（不推荐作最终 house）。**

### 3.2 A-坡屋面（左+右各 1，真倾角）

意图：左片一腰贴左檐，另一腰沿进深方向的「坡向」指向屋脊端点。

半跨 run = 0.5；坡向腰长 = 1 →  
`rise = √(1²−0.5²) = √0.75 ≈ 0.866`，**坡角 = 60°**，脊高 `y = 1.866`。

**左片面顶点（直角在左后檐）：**

| 顶点 | 坐标 | 角色 |
|------|------|------|
| RA | `(-0.5, 1.000, -0.5)` | 直角 / 后左檐 |
| FA | `(-0.5, 1.000,  0.5)` | 前左檐 |
| RB | `( 0.0, 1.866, -0.5)` | 脊线后点 |

| 边 | 长 mm | 端点 | 磁吸 |
|----|-------|------|------|
| 檐边 RA–FA | 75 | 左墙顶 | ✅ → 左墙顶 |
| 坡向 RA–RB | 75 | 后横切 | 右片对称边可在 **后点** 相遇，但非整段脊 |
| 斜边 FA–RB | 106 | 对角 | 无 106 墙边；与右片无等长共线边 |

右片镜像：`(+0.5,1,±0.5)` 与 `(0,1.866,-0.5)`。

**屋脊：** 需要 `z∈[-0.5,0.5]`、`x=0`、`y=1.866` 的整边；本取向下直角片 **只有后横切短边，没有满长脊边** → 左右片 **不能** 以 MAG-002 共边互吸（仅可能共点）。

| 项 | 结论 |
|----|------|
| 檐口边长 | ✅ |
| 左右共脊边 | ❌ |
| 倾角 60° | ❌ 触发现规则 |
| 视觉双坡 | ✅（若允许倾角） |

**可行性：几何上可「盖住」左右坡，但无合格脊边 + 倾角违规 → 现规则下不可落地。**

### 3.3 A-斜边贴墙？

斜边 106 ≠ 75 → **不能** 作檐口。否决。

## 4. 方案 B — 大三角形组合

### 4.1 B-竖双山墙（前+后各 1 large，推荐「规则内最大收益」）

大三角底 = 75，贴前后檐；平面竖直；尖朝上；**峰在正中**。

**前片（替换当前 step 5，并对称加后片）**

| 边 | 长 mm | 端点（竖立后） | 磁吸 |
|----|-------|----------------|------|
| 底 | 75 | `(-0.5,1,0.5)→(0.5,1,0.5)` | ✅ 窗顶 |
| 腰 L | ≈142 | 左底 → 尖 `(0, 1+H, 0.5)`，H≈1.827 | 自由 / 可与装饰共边（本方案不用） |
| 腰 R | ≈142 | 右底 → 尖 | 同上 |

尖点：`(0, 2.827, 0.5)`（前）、`(0, 2.827,-0.5)`（后）。  
位姿：与现 large 同族，`Rx=±90`，质心约 `[0, 1+LARGE_CENTROID_TO_BASE, ±0.5]`。

| 项 | 结论 |
|----|------|
| 边长 / 倾角 | ✅ / ✅ |
| 正中山尖 | ✅ |
| 前后层次 | ✅ |
| **真双坡屋面 / 侧面坡度** | ❌ 仍是竖板（比现状多一块后山墙） |
| 片数 | 5 + 2 large = **7** |
| 形状用量 | square×3, window×1, large-triangle×2 |

**可行性：现规则下唯一完整可验收路径；满足「山墙成对」，不满足「侧面可见坡度」。**

### 4.2 B-坡屋面（左+右各 1 large，尖在脊中）

底贴左/右檐；尖共点于 `(0, 1+rise, 0)`。

`H = LARGE_TRI_HEIGHT ≈ 1.827`，run=0.5 →  
`rise = √(H²−0.5²) ≈ 1.757`，**坡角 ≈ 74.1°**，脊高 `y ≈ 2.757`。

**左片顶点**

| 顶点 | 坐标 |
|------|------|
| 后左檐 | `(-0.5, 1.000, -0.5)` |
| 前左檐 | `(-0.5, 1.000,  0.5)` |
| 脊尖 | `( 0.0, 2.757,  0.0)` |

| 边 | 长 mm | 磁吸 |
|----|-------|------|
| 底（檐） | 75 | ✅ 左墙顶 |
| 两腰 | ≈142 | 仅可能与另一大三角腰共边；本布局腰连檐角→脊尖，**左右片腰不重合** |
| 左右之间 | — | **仅共尖点，无共边** |

校验：新片只需与**某一**已放片共边 → 左贴左墙、右贴右墙即可 **realOk**；脊不必互吸。

| 项 | 结论 |
|----|------|
| 檐口磁吸 | ✅ |
| 倾角 ~74° | ❌ 现规则 |
| 侧面双坡可读 | ✅ 强 |
| 屋脊共边 | ❌（共点） |

**可行性：造型最优；必须先批准「屋面倾角例外」，且不改边长阈值。**

### 4.3 B-其它组合（摘要）

| 变体 | 结论 |
|------|------|
| 维持 1× large（现状） | 已 visual fail |
| 4× large（前后山墙 + 左右坡） | 坡面仍要倾角例外；片数偏多，超教学简洁 |
| large 底贴檐 + 方片作坡 | 方片坡深 1 > 半跨坡长 0.707，45° 时脊不对中或穿插；同样倾角违规 |

## 6. 决策（已批准）

采用 **B 坡屋面**；局部 `posePolicy: 'house-roof'`；不放宽边长。  
精确参数见 `utils/house-roof.ts`（pitch≈74.114° 由 `atan2(rise,0.5)` 导出，非手写常量）。
